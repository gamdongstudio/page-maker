# 사진 취급 규칙 (가장 중요)

이 프로그램은 사진관에서 **실제 고객 사진**을 다룬다.
그래서 디자인이나 자동 생성보다 **원본 인물 보호**가 항상 우선한다.

## 절대 하지 않는 것

업로드한 사진 속 사람에 대해 아래를 바꾸지 않는다.

- 얼굴형 · 눈 · 코 · 입 · 표정
- 피부의 실제 특징
- 나이대
- 헤어스타일 · 의상 · 체형
- 인물 자체

"더 예쁘게 / 더 젊게 / 더 잘생기게" 같은 이유로
얼굴을 새로 만들어내거나 보정하지 않는다.

**이 프로그램에는 사진을 새로 만들어내는 기능이 없다.**
사진은 올린 그대로를 쓰고, 크기와 위치만 다룬다.

## 허용하는 것

- 사진 크기 조절 (원본 비율 그대로, 찌그러짐 없음)
- 사진 위치 조절
- 레이아웃에 맞춘 자연스러운 배치
- 잘림이 필요할 때도 얼굴이 잘리지 않도록 위쪽을 우선 보기
- 표시용 최소한의 밝기·색감 정리

위 작업도 원래 얼굴과 인물을 바꾸면 안 된다.

## 사용자가 직접 요청한 경우

"정장으로 바꿔줘", "배경을 흰색으로 바꿔줘" 처럼
사용자가 분명히 요청했을 때만 그 요소를 바꾼다.

이때도 **요청한 것만** 바꾸고
얼굴 · 헤어스타일 · 체형 · 피부 · 표정은 원본 그대로 둔다.

지금 프로그램은 이런 사진 변경 기능을 **연결하지 않았다.**
연결하기 전까지는 있는 척하지 않는다.

## 코드에서 지키는 자리

| 하는 일 | 파일 |
|---|---|
| 올린 사진 크기 줄이기 (자르지 않음) | `src/utils/image.ts` 의 `fitForPage` |
| 보여줄 때 맞추기 (얼굴 보호 초점) | `src/utils/image.ts` 의 `photoStyle`, `focusY: 42` |
| 사진 자동 배치 | `src/services/ai/studioPlanner.ts` — 고르고 놓기만 한다 |
