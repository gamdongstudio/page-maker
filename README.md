# SAY PAGE MAKER PRO

네이버 스마트스토어 상품 상세페이지를 초보자도 쉽게 만드는 웹 도구.

```bash
npm install
npm run dev      # http://localhost:5180
```

**링크로 가져오기**를 쓰려면 수집 서비스도 같이 켭니다. (새 명령창에서 한 번만)

```bash
cd collector
npm start
```

쓰는 자리(포트)는 `collector.config.json` **한 곳**에서만 관리합니다.
그 자리를 다른 프로그램이 이미 쓰고 있으면 **켜지지 않고 그대로 알려줍니다.**
화면도 "켜져 있다"고 잘못 말하지 않습니다 — 같은 자리에 있는 다른 프로그램과 구분해서 확인합니다.

## 쓰는 법

처음 열면 **어떻게 시작할지** 물어봅니다. 직접 만들기 / AI로 만들기 / SAY PROMPTER로 만들기 중에 고르면 되고,
그냥 샘플 상품으로 둘러봐도 됩니다. 고른 뒤에도 언제든 다른 방식으로 바꿀 수 있습니다.

왼쪽은 실시간 미리보기, 오른쪽은 7단계 제작도구입니다. 가운데 선을 끌어 폭을 바꿀 수 있습니다.

| 단계 | 하는 일 |
|---|---|
| ① 상품정보 | 상품명·가격·소개·장점 (추가정보는 더보기 안에) |
| ② 사진·미디어 | 사진 올리기, 대표사진 지정, 순서 바꾸기, 사진 맞춤, 대문 사진 모양 |
| ③ 메뉴 구성 | 메뉴 추가·편집·복제·숨기기·삭제·순서 바꾸기 |
| ④ 디자인 | 간편 스타일 6종 + 세부 설정 + 참고 캡처에서 느낌 가져오기 |
| ⑤ AI 만들기 | 제목·메뉴 구성·카피 추천 (전체/선택 적용) |
| ⑥ SAY PROMPTER | 원하는 수정을 말하면 GPT/Claude/Codex용 요청문 생성 |
| ⑦ 검수·완성 | 스마트스토어 체크 → 전체 이미지 / 분할 JPG / ZIP |

## 특징

- **사진 자동 맞춤** — 가로·세로·정사각형 어떤 사진을 넣어도 찌그러지거나 이상하게 잘리지 않습니다.
- **큰 사진 자동 정리** — 휴대폰 사진처럼 아주 큰 사진은 올릴 때 상세페이지에 알맞은 크기로 자동으로 줄입니다.
  비율 그대로이고 잘라내지 않으며, 원래 작은 사진은 키우지 않습니다. 출력 선명도는 그대로입니다.
- **미리보기 = 결과물** — 미리보기와 출력이 같은 화면을 씁니다. 미리보기만 예쁜 일이 없습니다.
- **자동저장** — 입력하는 즉시 저장됩니다. 새로고침·브라우저 종료 후에도 이어서 작업할 수 있습니다.
  사진을 많이 넣어도 저장되도록 넉넉한 저장소를 씁니다. (18MB·사진 12장 확인)
- **실행취소 / 다시하기** — Ctrl+Z, Ctrl+Shift+Z
- **작업파일 저장·불러오기** — 상품정보·사진·메뉴·디자인이 그대로 복원됩니다.
- **대문 사진 모양** — 맨 위 사진을 자동 추천 / 가로형 / 정사각형 / 세로형 중에 고를 수 있습니다.
- **참고 캡처에서 느낌 가져오기** — 마음에 드는 상세페이지를 캡처해서 올리면
  색 분위기·여백·구성만 읽어 지금 상품에 맞게 제안합니다. 남의 페이지를 그대로 베끼지 않습니다.
- **AI 없이도 전부 동작** — AI는 연결되면 더 좋아지는 보조 기능입니다.
- **링크로 가져오기** — 네이버 블로그·스마트플레이스·홈페이지 주소를 넣으면
  상호·주소·전화번호·영업시간·가격을 읽어옵니다. **바로 덮어쓰지 않고 확인 화면을 먼저** 보여주며,
  이미 적어두신 값이 다르면 그 값을 먼저 둡니다. 못 찾은 항목은 **지어내지 않고 비워둡니다.**
  스마트플레이스는 네이버 쪽 화면이 자주 바뀌어 못 읽을 때가 있고, 그때는 그대로 알려줍니다.

## LITE / PRO

프로그램은 하나입니다. 위쪽 버튼으로 보여주는 범위만 바꿉니다.

| | LITE | PRO |
|---|---|---|
| 메뉴 종류 | 기본 10종 | 전체 22종 |
| 디자인 | 스타일 + 색상 | + 크기·여백·글씨·버튼·정렬 |
| 참고 캡처 분석 · 동영상 | 없음 | 있음 |
| AI | 제목·구성 추천 | + 상품/고객 분석, 장점 정리 |
| 작업파일 저장·불러오기 | 없음 (자동저장은 동작) | 있음 |
| 검수 · 출력 | 전체 이미지 저장 | + 스마트스토어 체크 · 분할 JPG · ZIP |

LITE 도 실제 업무에 그대로 쓸 수 있습니다.

## 알아두실 점

- AI 추천은 아직 실제 AI에 연결되지 않았습니다. 지금은 입력한 상품정보를 규칙대로 정리해 보여주며,
  화면에도 그렇게 표시됩니다. (가짜로 AI인 척하지 않습니다)
- SAY PROMPTER는 요청문을 만들어 주는 단계까지 구현되어 있습니다.
- 참고 캡처 분석은 AI가 아니라 사진의 **색과 여백을 직접 재서** 계산한 결과입니다.
  못 잰 항목은 "짐작하기 어려웠어요"라고 그대로 말합니다. 캡처 사진은 저장하지 않습니다.
- 저장은 이 브라우저 안에만 됩니다. 서버로 보내지 않습니다.
  다른 기기로 옮기거나 확실히 남겨두려면 **작업파일 저장**을 쓰세요.
